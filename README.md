## Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias base da web, sem a necessidade de frameworks complexos, focando em performance e estruturação semântica:

*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Estilização, layout responsivo utilizando CSS Grid e Flexbox, e variáveis de ambiente.
*   **JavaScript (Vanilla):** Lógica simples para alternância de idiomas (Português/Inglês) de forma dinâmica, sem recarregar a página.

---

## Funcionalidades

*   **Bilingue (PT-BR / EN-US):** O usuário pode alternar o idioma de todo o site com um único clique.
*   **Adaptabilidade:** O layout se adapta perfeitamente a dispositivos móveis (celulares) e telas maiores (desktops e tablets).
*   **Download de Currículo:** A seção de currículo atualiza automaticamente o arquivo de download e a imagem de preview de acordo com o idioma selecionado pelo usuário.
